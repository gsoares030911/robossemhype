ROBÔS SEM HYPE

Política de Privacidade

Última atualização: 2 de novembro de 2026

Esta política explica como o canal Robôs Sem Hype e a sua ferramenta interna de publicação, o aplicativo "Robôs Sem Hype Publisher", tratam dados. Contato: robossemhype@gmail.com.

1. O que é o Robôs Sem Hype Publisher

É uma ferramenta de uso exclusivo e interno do próprio canal. Ela serve apenas para publicar vídeos, legendas e thumbnails nas contas do próprio canal (YouTube e Instagram) e para ler as estatísticas desses vídeos. Ela não é oferecida ao público e não acessa contas de outras pessoas.

2. Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao interagir com o aplicativo, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google.

Permissões solicitadas e para que servem:

  • youtube.upload: enviar os vídeos do canal.
  • youtube.force-ssl: enviar legendas e thumbnails dos vídeos do canal.
  • yt-analytics.readonly: ler estatísticas (visualizações, tempo assistido, inscritos) dos vídeos do canal, para relatórios internos.

3. Uso da API do Instagram

O aplicativo usa a API do Instagram (Meta) apenas para publicar Reels na conta profissional do próprio canal (@robossemhype) e consultar o status dessas publicações. Os dados tratados pela Meta seguem a Política de Privacidade da Meta.

4. Quais dados guardamos

  • Credenciais de acesso (tokens) das contas do canal, guardadas de forma criptografada em servidor próprio.
  • Estatísticas agregadas dos vídeos do canal, para relatórios internos.
  • Registros técnicos das publicações feitas (data, vídeo, resultado).

Não coletamos dados de espectadores, seguidores ou visitantes. Não vendemos, alugamos nem compartilhamos dados com terceiros, e não usamos os dados para publicidade.

5. Uso Limitado (Google)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Por quanto tempo guardamos

Os tokens ficam guardados enquanto a ferramenta estiver em uso e são apagados quando o acesso é revogado. As estatísticas e os registros técnicos são mantidos enquanto o canal existir, para comparação histórica.

7. Como revogar o acesso

O acesso concedido pode ser revogado a qualquer momento em Configurações de segurança da Conta Google (Google/YouTube) e nas configurações de "Apps e sites" do Instagram (Meta).

8. Este site

Este site não usa cookies, não tem rastreamento nem anúncios. Ele é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP) conforme a política de privacidade do GitHub.

9. Seus direitos (LGPD)

Em caso de dúvida ou para exercer direitos previstos na Lei Geral de Proteção de Dados (Lei 13.709/2018), escreva para robossemhype@gmail.com.
